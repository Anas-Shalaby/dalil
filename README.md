# دليل — Dalil

> حوّل خطوات شغلك إلى دليل واضح.

**دليل** إضافة Chrome عربية بالكامل (RTL) تساعدك على تسجيل التفاعل الذي تقوم به على صفحة ويب، أو توثيق برنامج على سطح المكتب بلقطات تختارها بنفسك، ثم توليد دليل خطوات مرقّم ومصوّر يمكنك تحريره وطباعته أو حفظه بصيغة PDF.

- المنتج يعمل بالكامل على جهازك: **بلا خادم، بلا قاعدة بيانات، بلا حسابات، بلا APIs مدفوعة، وبلا ذكاء اصطناعي.**
- توليد التعليمات يتم بقواعد حتمية بسيطة (ليست AI).
- كل الأدلة واللقطات محفوظة محليًا في متصفحك.
- **استوديو PDF**: صفحة تصدير احترافية بمعاينة حية، ستة قوالب، شعارات وهوية، وتخطيط ذكي للصفحات — كلها محلية.

---

## 1. المتطلبات المسبقة

- **Node.js** الإصدار 18 أو أحدث (تم التطوير على 20).
- **npm** الإصدار 9 أو أحدث.
- **Google Chrome** الإصدار 116 أو أحدث (لاستخدام `chrome.scripting` و`chrome.tabs.captureVisibleTab` بشكل موثوق).

لا يوجد أي مفتاح API أو ملف بيئة (`.env`).

## 3. أوامر التطوير والبناء

| الغرض | الأمر |
| --- | --- |
| وضع التطوير (إعادة بناء تلقائية عند التعديل) | `npm run dev` |
| فحص الأنواع فقط | `npm run typecheck` |
| الاختبارات الآلية (Vitest) | `npm test` |
| مراقبة الاختبارات أثناء التطوير | `npm run test:watch` |
| بناء الإنتاج | `npm run build` |

`npm run dev` يبني المشروع في وضع المراقبة إلى مجلد `dist`؛ بعد كل تعديل اضغط زر **Reload** في صفحة `chrome://extensions` لتحديث الإضافة.

مخرجات البناء تظهر في مجلد `dist/`:

```
dist/
├── manifest.json        # إعداد Manifest V3
├── background.js        # Service worker (منسّق التسجيل)
├── content.js           # سكربت التسجيل المحقون في الصفحة
├── popup.html           # النافذة المنبثقة
├── editor.html          # محرر الدليل
├── library.html         # مكتبة الأدلة المحفوظة
├── capture.html         # جلسة التقاط سطح المكتب
├── print.html           # صفحة الطباعة / PDF
├── studio.html          # استوديو PDF (تصميم وتصدير)
├── privacy.html         # سياسة الخصوصية
├── icons/               # أيقونات الإضافة
└── assets/              # ملفات JS/CSS والخطوط المحلية
```

## 4. تحميل الإضافة في Chrome (وضع المطور)

1. نفّذ `npm run build`.
2. افتح `chrome://extensions` في Chrome.
3. فعّل **وضع المطوّر (Developer mode)** من أعلى يمين الصفحة.
4. اضغط **Load unpacked** واختر **مجلد `dist`** (وليس جذر المشروع).
5. ستظهر أيقونة **دليل** في شريط الأدوات. عند أول تثبيت سيُفتح تبويب سياسة الخصوصية تلقائيًا.

> ملاحظة مهمة: إذا حمّلت مجلد المشروع كاملًا بدل `dist` فلن تعمل الإضافة؛ يجب اختيار `dist` تحديدًا.

## 5. كيفية اختبار التسجيل

1. افتح موقعًا عاديًا مثل صفحة نموذج أو لوحة تحكم (مثال: `https://example.com`).
2. اضغط أيقونة **دليل** في شريط الأدوات.
3. اضغط **ابدأ التسجيل**.
   - أول مرة قد يعرض Chrome طلب إذن للتبويب النشط؛ اقبله.
   - تظهر في أسفل يسار الصفحة لوحة **جارٍ التسجيل** مع عدّاد الخطوات.
4. نفّذ خطوات فعلية على الصفحة:
   - اضغط زرًا أو رابطًا → تُسجَّل خطوة نقرة مع لقطة شاشة.
   - اكتب في حقل نصي → تُسجَّل خطوة إدخال **دون حفظ النص المكتوب**.
   - اختر عنصرًا من قائمة اختيار → تُسجَّل خطوة اختيار.
5. استخدم **إيقاف مؤقت / متابعة** من النافذة المنبثقة أو من اللوحة داخل الصفحة.
6. اضغط **إنهاء وعرض الدليل**؛ سيُفتح تبويب المحرر مع الخطوات المسجّلة.
7. في المحرر: حرّر التعليمات، أعِد الترتيب، احذف أو أضف خطوات أو لقطات.
8. اضغط **تصدير PDF** في المحرر وانتقل إلى **استوديو PDF** لاختيار قالب وتخصيص المستند ثم حفظه كـ PDF (أو استخدم **طباعة / PDF متجه** من الاستوديو).
9. للرجوع لاحقًا: **أدلتي** من النافذة المنبثقة أو من المحرر. الأدلة تبقى بعد إغلاق المتصفح وإعادة فتحه.

## 6. التقاط من الكمبيوتر (تطبيقات خارج المتصفح)

هذا الوضع مخصص لتوثيق برنامج أو نافذة خارج Chrome. لا يستخدم زر اختصار عامًا ولا طبقة عائمة فوق التطبيقات الأخرى؛ بل يفتح **صفحة إضافة مستقلة** تبقى مفتوحة أثناء الجلسة.

1. افتح النافذة المنبثقة واضغط **التقاط من الكمبيوتر** (أو الزر نفسه في **أدلتي**).
2. اضغط **اختيار نافذة أو شاشة**. ستفتح نافذة Chrome الرسمية لاختيار المصدر.
   - **المفضّل: نافذة البرنامج المستهدف**، لأن اختيار الشاشة الكاملة قد يُظهر واجهة دليل نفسها داخل اللقطات.
   - لا يبدأ أي التقاط قبل اختيارك الصريح.
3. انتقل إلى البرنامج، نفّذ الإجراء، ثم ارجع إلى صفحة دليل واضغط **التقاط خطوة**.
   - كل ضغطة تلتقط **إطارًا واحدًا فقط** (JPEG) وتضيفه كخطوة طبيعية.
   - يمكنك كتابة وصف الخطوة مباشرة، ويُحفظ تلقائيًا.
4. كرر لكل خطوة. يمكنك حذف أي خطوة ولقطتها من نفس الصفحة.
5. اضغط **إنهاء التوثيق وفتح المحرر** لاستكمال التحرير والتوضيحات، ثم **تصدير PDF**.
6. لإيقاف المصدر دون إنهاء الجلسة، استخدم **إيقاف الالتقاط**؛ يمكنك بعدها اختيار مصدر جديد.

قيود مهمة لهذا الوضع:

- Chrome هو من يعرض نافذة اختيار المصدر؛ لا يمكن للإضافة اختيار نافذة برنامج عنك.
- لا يمكن التقاط نافذة لا تسمح بها واجهة Chrome (مثل بعض النوافذ المحمية أو المحتوى الأسود).
- إذا اخترت الشاشة الكاملة وظهرت صفحة دليل، ستظهر ضمن اللقطة. اختر نافذة البرنامج لتفادي ذلك.
- جلسة التقاط سطح مكتب واحدة فقط في كل مرة؛ فتح جلسة ثانية يعرض رسالة تعارض.
- لا يوجد اختصار لوحة مفاتيح عام ولا زر عائم فوق البرامج الأخرى؛ الالتقاط يتم من صفحة دليل.

دليل الاختبار اليدوي التفصيلي: [`docs/desktop-capture-test-plan.md`](docs/desktop-capture-test-plan.md).

## 7. استوديو PDF — تصميم وتصدير مستند احترافي

زر **تصدير PDF** في المحرر (أو من بطاقة الدليل في **أدلتي**) يفتح **استوديو PDF** في تبويب مستقل (`studio.html`)؛ لا يبدأ التنزيل فورًا بل يتيح لك تصميم مستند احترافي ثم تصديره.

**ماذا تحصل عليه:**

- **ستة قوالب احترافية متمايزة**: تنفيذي احترافي، بسيط تحريري، تعليمي، تدرّج عصري، توثيق تقني، هوية الشركة — لكل قالب غلاف مستقل وهوامش وترقيم وهوية بصرية.
- **معاينة حية حقيقية** للصفحات: زوم، تصفح بين الصفحات، والترقيم والهوامش كما ستظهر في الملف.
- **تخصيص كامل محليًا**: العنوان والعنوان الفرعي والوصف والمؤلف والجهة والتاريخ والملاحظة، الشعار، الألوان الأساسية، الخط (IBM Plex Sans Arabic أو Noto Naskh Arabic أو خط النظام)، المقاس (A4 أو Letter)، الاتجاه (طولي/عرضي)، الهوامش، التباعد، عرض اللقطة واستدارتها وانحيازها، أنماط ترقيم الخطوات، الترويسة والتذييل، وتخطيطات الغلاف (القالب/مركزي/منقسم).
- **التوضيحات على اللقطات تُحفظ كما هي**: الأسهم، المستطيلات، الإهليجات، النصوص، والعلامات كلها تُعرض في التصدير تمامًا كما تظهر في المعاينة.
- **مظاهر محفوظة محليًا**: احفظ الإعدادات الحالية كمظهر وأعد تطبيقه على أدلة أخرى (تخزّن المظاهر إعدادات التصميم فقط — لا عنوان الدليل ولا شعاره — حفاظًا على مساحة التخزين الافتراضية).
- **التصدير محلي بالكامل** عبر `jsPDF` ومحرّر canvas مخصص يتعامل مع العربية، مع شريط تقدّم أثناء الإنشاء.، ولا يُرفع أي شعار أو محتوى إلى خادم. أكثر من 80 صفحة تُرفض برسالة واضحة بدلًا من المخاطرة بتعطّل المتصفح.
- **طباعة / PDF متجه**: خيار بديل داخل الاستوديو يفتح نافذة Chrome الأصلية بحجم الصفحة الذي اخترته (مفيد إن أردت نصوصًا قابلة للتحديد بدل الصور عالية الدقة).

**خطوات سريعة:**

1. في المحرر اضغط **تصدير PDF**.
2. اختر قالبًا من المعرض، غيّر الألوان والخط والورق واتجاه الصفحة والتذييل والغلاف.
3. راجع المعاينة ثم اضغط **تصدير PDF**، أو استخدم **طباعة / PDF متجه** من نافذة Chrome.
4. أعد استخدام مظهرك المفضل من لوحة «الإعدادات المحفوظة» في المرة القادمة.

## 8. المواقع المدعومة وغير المدعومة

**مدعومة:**

- صفحات الويب العادية (`http` و`https`) في التبويب النشط.
- النقر على الأزرار والروابط وعناصر التحكم الشائعة (`role="button"`, `role="link"`, `role="tab"`, `role="menuitem"`, `role="checkbox"`, `role="radio"`, `role="switch"`).
- الكتابة في حقول الإدخال النصية (يُسجَّل نوع الحقل وتسميته فقط).
- الاختيار من قوائم `select` المدعومة.
- لقطة شاشة تُلتقط بعد النقر مباشرة أثناء بقاء التبويب في المقدمة.

**غير مدعومة (بحدود واجهات Chrome، وليس خللًا في الإضافة):**

- صفحات المتصفح الداخلية: `chrome://`, `about:`, `devtools://`, `view-source:`.
- متجر Chrome الإلكتروني (محمي من عمل الإضافات).
- ملفات `file://` المحلية.
- الإطارات المتقاطعة المصدر (يُسجَّل ما تراه الصفحة الرئيسية فقط).
- المواقع التي تمنع حقن السكربتات أو تمنع لقطات الشاشة.

عند تعذّر التقاط لقطة، **يُحفظ الإجراء دون صورة** وتظهر ملاحظة توضيحية في المحرر. لا تدّعي الإضافة نجاح التقاط اللقطة إن فشلت واجهة Chrome.

## 9. خصوصية البيانات

- **لا إرسال للبيانات:** لا توجد طلبات شبكة، ولا تحليلات، ولا مكتبات تتبّع. يمكن استخدام الإضافة دون إنترنت.
- **تخزين محلي فقط:** بيانات الأدلة في `chrome.storage.local`، ولقطات الشاشة في **IndexedDB**.
- **لا كلمات مرور ولا بيانات حساسة:** لا يُخزَّن أي نص مكتوب في أي حقل. الحقول الحساسة (كلمة المرور، البطاقات، أكواد التحقق، `autocomplete` الحساس) تُسجَّل كإجراء «تم تعبئة الحقل» فقط.
- **لا لقطات لحقول الإدخال:** تُتجاهل اللقطات لحقول الإدخال والقوائم ولحالات الإجراءات السريعة، ويُشرح السبب داخل الدليل.
- **أذونات محدودة:** `storage` و`activeTab` و`scripting` و`desktopCapture` فقط — **بدون `host_permissions`** وبدون وصول دائم لجميع المواقع.
  - `desktopCapture` مطلوب فقط لإظهار نافذة Chrome الرسمية لاختيار نافذة/شاشة عند استخدام **التقاط من الكمبيوتر**. لا يمنح الإضافة وصولًا تلقائيًا إلى الشاشة؛ الاختيار يظل بيدك في كل مرة.
- **مؤشّر تسجيل واضح:** لوحة حمراء نابضة داخل الصفحة أثناء التسجيل، مع زر إنهاء فوري.
- تعرض صفحة `privacy.html` (وتُفتح من النافذة المنبثقة) شرحًا مبسّطًا لكل ما سبق.

### لماذا IndexedDB للقطات؟

لقطات الشاشة تُلحق بسرعة حد `chrome.storage.local` (حوالي 10 ميجابايت). لذلك نحفظ **بيانات الأدلة الوصفية** في `chrome.storage.local`، و**الصور (base64)** في قاعدة `dalil-media` داخل **IndexedDB**. هذا يبقي المزامنة خفيفة ويمنع امتلاء التخزين من الصور. عند حذف دليل تُحذف لقطاته المرتبطة تلقائيًا.

## 10. القيود المعروفة

- **لقطات الشاشة تتطلب تبويبًا نشطًا ومرئيًا.** إن لم يكن التبويب في المقدمة، تُسجَّل الخطوة بلا لقطة مع ملاحظة.
- **حقول الإدخال لا تُصوَّر** لحماية الخصوصية؛ أضف لقطة يدويًا من المحرر عند الحاجة.
- **الخطوات السريعة المتتابعة** (أقل من ~0.35 ثانية) قد تُسجَّل بلا لقطة لتقليل الضوضاء.
- **إنشاء نسخة من دليل يحتوي لقطات** يتم بدون نسخ الصور (لتفادي مضاعفة التخزين)، وتُعرض ملاحظة بذلك.
- **حقن السكربت** يتم فقط عند بدء التسجيل (`activeTab`)، لذا لا يعمل التسجيل في تبويب لم تبدأ منه.
- التسجيل يستهدف التبويب الذي بدأت منه؛ لا تسجيل متعدد التبويبات في نفس الوقت.
- التقاط إجراءات الصفحة يعتمد على `document.title` و`innerText`؛ قد تكون بعض التسميات عامة، ويمكن تعديل النص دائمًا في المحرر.
- الوضع الفاتح مُصمَّم بعناية أولًا؛ الوضع الداكن غير مضمون في هذا الإصدار.
- **التقاط سطح المكتب** يعتمد على `chrome.desktopCapture`؛ المتصفح هو من يعرض قائمة المصادر، وقد يختلف شكلها بين أنظمة التشغيل.
- لا يمكن التقاط محتوى محمي أو نافذة يرفضها Chrome، ولا يوجد اختصار عام أو طبقة عائمة فوق التطبيقات.
- عند اختيار **الشاشة الكاملة** قد تظهر واجهة دليل نفسها في اللقطة؛ يُنصح باختيار نافذة البرنامج.
- إذا أُغلق مصدر الالتقاط أو توقف بثه، تُحفظ الخطوات السابقة وتظهر رسالة عربية لإعادة اختيار مصدر.
- جلسة سطح المكتب واحدة فقط في كل مرة، ويُمنع فتح جلسة ثانية حتى إنهاء الجلسة الحالية أو إغلاق تبويبها.

## 11. قائمة اختبار يدوية

- [ ] `npm install` يعمل بلا أخطاء.
- [ ] `npm run typecheck` يمر بلا أخطاء.
- [ ] `npm test` يمر بلا أخطاء.
- [ ] `npm run build` ينتج مجلد `dist` كاملًا (manifest + html + background + content + capture).
- [ ] تحميل `dist` عبر `chrome://extensions` → Load unpacked ينجح دون تحذيرات manifest.
- [ ] النافذة المنبثقة تُفتح وتُظهر زر **ابدأ التسجيل** والزر الثانوي **أدلتي**.
- [ ] على `https://example.com`: البدء يعرض لوحة «جارٍ التسجيل» وعدّاد خطوات.
- [ ] النقر على رابط يُسجَّل كخطوة نقرة مع لقطة شاشة.
- [ ] الكتابة في حقل نصي تُسجَّل كخطوة إدخال بلا حفظ للنص وبلا لقطة.
- [ ] إيقاف مؤقت/متابعة يعمل من النافذة ومن اللوحة داخل الصفحة.
- [ ] **إنهاء وعرض الدليل** يفتح المحرر مع الخطوات.
- [ ] تحرير نص تعليمة يُحفظ تلقائيًا ويظهر مؤشر «تم الحفظ».
- [ ] تحريك خطوة لأعلى/أسفل يعمل، وحذف خطوة يطلب تأكيدًا.
- [ ] إضافة خطوة يدوية وإضافة/استبدال/إزالة لقطة (PNG/JPG/WebP) تعمل.
- [ ] إعادة فتح Chrome: الأدلة موجودة في **أدلتي** وبحث العنوان يعمل.
- [ ] إعادة تسمية، إنشاء نسخة، حذف نهائي (بتأكيد) تعمل.
- [ ] **تصدير PDF** في المحرر يفتح **استوديو PDF** بلا أخطاء.
- [ ] **تصدير PDF** من الاستوديو ينزّل ملفًا عربيًا RTL نظيفًا بتخطيط صحيح وبلا قصّ/تداخل.
- [ ] **طباعة / PDF متجه** من الاستوديو يفتح نافذة Chrome بحجم الصفحة المختار.
- [ ] محاولة التسجيل على `chrome://extensions` تُظهر رسالة «صفحة غير مدعومة» بوضوح (بلا ادّعاء نجاح).
- [ ] تحقق أن الإضافة لا تُرسل أي طلب شبكة (DevTools → Network فارغ أثناء التسجيل).
- [ ] **التقاط من الكمبيوتر**: الزر يفتح `capture.html`، ونافذة Chrome لاختيار المصدر تظهر عند الطلب.
- [ ] اختيار نافذة برنامج ثم «التقاط خطوة» يضيف خطوة بلقطة مقروءة النص إلى الدليل.
- [ ] اختيار مصدر ثانٍ أثناء وجود مصدر نشط ممنوع حتى «إيقاف الالتقاط».

## 14. صفحة الهبوط — Marketing Landing

صفحة هبوط احترافية بالعربية (RTL) لمبيعات الإضافة، مستقلة عن كتلة التطوير وموحّدة بعلامة Dalil.

- **المحتوى**: هيدو → الثقة → المشكلة → المميزات → كيف نعمل → العرض التفاعلي → الاستخدامات → قبل/بعد → الخصوصية → الأسئلة الشائعة → دعوة ختامية → فوتر.
- **الإعداد المركزي**: `src/shared/launch.ts` — يحتوي على رابط Chrome Web Store الفعلي للإضافة وروابط placeholder للسياسة والعرض.
- **المكوّنات**: `src/landing/` — `LandingPage`, مكوّنات الأقسام (`Nav`, `Hero`, `Trust`, `Problem`, `Features`, `HowItWorks`, `Demo`, `UseCases`, `BeforeAfter`, `Privacy`, `Faq`, `FinalCta`, `Footer`), مكوّنات مساعدة (`CtaButton`, `LazySection`) وقوالب بصرية CSS/SVG (`ProductMockup`, `featureVisuals`).
- **HTML**: `landing.html` — ترميز عربي RTL كامل، SEO (عنوان، وصف، OG/Twitter، canonical placeholder، favicon) وإشارات Open Graph.
- **الإعداد**: يولّد `vite build` صفحة `dist/landing.html` ضمن مدخلات البناء العامة.

ملاحظات: لا تُظهر الصفحة أرقامًا أو تقييمات أو شهادات وهمية؛ والقيم غير المعروفة (مثل نطاق سياسة الخصوصية) موثّقة كـ placeholders.
