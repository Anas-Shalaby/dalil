# خطة الاختبار اليدوي — استوديو PDF

هذه الخطة تغطي سلوك التصدير الحقيقي للمستند داخل Chrome العادي. لا يمكن محاكاة
نافذة الطباعة الفعلية ولا رؤية الناتج على الشاشة كما يراه المستخدم في بيئة
الاختبارات الآلية، لذلك تبقى هذه البنود **يدوية** ولا تُعتبر ناجحة حتى تُنفَّذ
وتُسجَّل فعليًا.

توفر هذه الحزمة أيضًا `npm run verify:pdf`، وهي تولّد ملفات PDF نموذجية داخل
Chrome وتكتبها في `output/verify/` — وهي تحقق **حقيقي** أن خط أنابيب التصدير
(renderer + pdf-lib) ينتج ملفات صالحة بصفحات صحيحة، لكنها ليست بديلًا عن تجربة
المستخدم الكاملة.

ملفات PDF النموذجية المولّدة فعلًا أثناء التطوير (يمكن فحصها):

```
output/verify/verify-ar-executive.pdf        # تنفيذي احترافي
output/verify/verify-ar-minimal.pdf          # بسيط تحريري
output/verify/verify-ar-tutorial.pdf         # دليل تعليمي
output/verify/verify-ar-gradient.pdf         # تدرّج عصري
output/verify/verify-ar-technical.pdf        # توثيق تقني
output/verify/verify-ar-brand.pdf            # هوية الشركة
output/verify/verify-en-minimal.pdf          # إنجليزي LTR
output/verify/verify-letter-landscape-brand.pdf  # Letter أفقي
output/verify/verify-annotated-large-tutorial.pdf  # لقطات معلّمة
output/verify/verify-no-cover-technical.pdf  # بدون غلاف
```

---

## 1. التجهيز

1. نفّذ:
   ```bash
   npm install
   npm run typecheck
   npm test
   npm run build
   npm run verify:pdf
   ```
2. افتح `chrome://extensions`، فعّل وضع المطوّر، ثم **Load unpacked** واختر `dist`.
3. افتح دليلًا متوسطًا (8–20 خطوة) في المحرر.
4. جهّز DevTools لصفحة الاستوديو لمراقبة Console وNetwork أثناء التصدير.

## 4. معايير القبول

- P1–P11 وP18 ناجحة في Chrome عادي.
- P12 وP13: لا يوجد تحول/اقتطاع للنصوص العربية أو الإنجليزية.
- لا ملفات PDF فارغة، ولا صفحات فارغة غير مقصودة.
- التوضيحات فوق اللقطات محفوظة كما في المعاينة.
- التصدير لا يتطلّب أي اتصال بالشبكة ولا أي صلاحيات أو مفاتيح إضافية.
- تنظيف بصري للقوالب الستة مطلوب فقط إذا ظهر خلل واضح في التوليد، وليس تفضيلًا ذوقيًا.

## 5. القيود المعروفة مسبقًا

- **جودة النص في PDF**: التصدير يرسم المستند بأكمله كصورة عالية الدقة لكل صفحة، لذلك لا تكون النصوص في PDF قابلة للتحديد أو البحث. هذا مقصود لضمان تشكل العربية وال ligatures كاملة — الخيار البديل هو **طباعة / PDF متجه**.
- **حجم الملف**: المستندات الكبيرة مع صور كثيرة ستكون ملفات PDF كبيرة نسبيًا.
- **كثافة الصفحات**: مع لقطات كبيرة قد لا تتسع صفحتان من الخطوات في الصفحة الواحدة؛ السمات العالية (صورة كاملة العرض) أقل كثافة من المدمجة.
- **الأداء**: المستندات كبيرة الجدًا (>80 صفحة) مرفوضة عمدًا؛ قسّمها بدلًا من المخاطرة بالتبويب.
- **المعاينة مقابل المطبوع**: المعاينة الحيّة تعرض نفس الهندسة تقريبًا؛ الاختلافات الصغيرة متوقع فقط فيما يتعلق بمحاذاة الخطوط بين محرك العرض في المعاينة ونافذة الطباعة.
